### 区域线路图

现行区域图位于 [`地图输出/区域线路图`](地图输出/区域线路图)，包括甘肃行旅、走河西、山陕漫游、回家路上、小城小记等系列。

每组成果通常包含：

- `.png`：可直接查看和用于网页发布的成图。
- `.qgz`：QGIS 工程。
- `.gpkg`：工程对应的矢量图层数据。

当前 QGIS 配套文件均低于 GitHub 的单文件大小限制，因此随成图一并发布。仓库不包含历史版本、校验报告、OSM 缓存、原始行政区/铁路底图和博客源文件。

## 制图文件

- [`QGIS旅行铁路地图制图流程.md`](QGIS旅行铁路地图制图流程.md)：现行视觉规范、数据口径和制图流程。
- [`制图工具/scripts/maps`](制图工具/scripts/maps)：地图构建与校验脚本。

部分构建脚本仍依赖本机 QGIS Python 环境以及未纳入仓库的原始数据源；仓库内的 `.qgz` 与配套 `.gpkg` 主要用于查看和继续编辑现行成果。
